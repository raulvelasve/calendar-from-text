# Política de Privacidad – Arbitro Calendar FBVIB La extensión **Arbitro Calendar FBVIB** no recopila, almacena ni comparte ningún tipo de información personal del usuario. Toda la información introducida (por ejemplo, el texto pegado de los partidos) se procesa localmente en el navegador y se guarda únicamente de forma temporal mediante la API de `chrome.storage.local`, con el único fin de mantener los datos mientras el usuario usa la extensión. Esta información nunca se envía a servidores externos. La extensión únicamente abre enlaces hacia Google Calendar para facilitar la creación de eventos. No se realiza ningún tipo de seguimiento ni análisis de uso. Si tienes dudas o quieres más información, puedes contactar con el desarrollador a través de la página de la extensión en Chrome Web Store.
